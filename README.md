Sizzle Station: a lunch-rush cooking game built for the make.fun best cooking game bounty. Take orders from the board, chop and grill ingredients, assemble dishes, and serve them before patience runs out.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Play with keyboard (WASD or arrow keys plus E) or mouse.
